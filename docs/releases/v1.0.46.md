# Phone Relay v1.0.46

## Changes

- Redesigned Phone Files with a sidebar of common places, a clickable path bar, search, Back and Forward, and a hidden-files toggle.
- Phone Files loads folders faster: one adb call per folder instead of three, instant revisits from a cache, and Camera and other places preloaded in the background.
- The mirror window's hover bar no longer appears over other windows that cover the mirror.
- Crisper traffic lights and darker toolbar icons on the mirror window in light mode.
