# Phone Relay v1.0.43

## Changes

- Added reply actions for supported Android notifications, with a native macOS reply window and delivery checks through the mirrored phone UI.
- Improved notification forwarding, opening, dismissal, mark-as-read, and reply handling, including safer matching when notifications repeat.
- Reworked USB and Wi-Fi discovery and reconnect state so USB remains available when Wi-Fi listener discovery fails.
- Parked confirmed missing Wi-Fi listeners and prompt for one-time wired recovery instead of repeatedly retrying a route that cannot accept connections.
- Tightened mirror lifecycle, phone file browsing, settings, and command timeout handling during connection changes.
